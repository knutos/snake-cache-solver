The script updates itself. Tampermonkey checks for new versions automatically, about once a day.

Usage

  1. Open the Snake cache link from the cache page (games.cachesleuth.com/snake-cache/?id=…).
  2. Click 🤖 Løs Snake in the bottom-right corner.
  3. The panel shows the coordinates, keyword and message when the run is accepted.

About

Snake Cache Solver plays CacheSleuth's Snake game for you. The game is deterministic. Each new game gets a seed from the server, and that seed fixes where every cache, power-up and piece of litter appears. When you win, the browser sends the list of turns to the server, which replays the game to check it.

The script fetches a fresh game and runs an exact copy of the game engine in your browser. It plans a safe route to each cache: a path is used only if the snake can still reach its own tail afterwards, so it never traps itself. Before anything is sent, the script replays the finished run locally to make sure it wins. It then submits the run the same way the game itself does.

It handles every board size, both solid and wrapping edges, power-ups and litter. By default it waits about as long as a real game would take before it submits. You can skip the wait with the checkbox in the panel.
